# תזכיר לי

מנהל משימות ידידותי בעברית (RTL) - אפליקציית PWA שרצה ישירות בדפדפן,
עם תזכורות, הקלטות קוליות, צילום ושמירה מקומית על המכשיר.

## יכולות

- **היום** - כל מה שמתוזמן להיום במקום אחד: משימות יומיות, שבועיות, חודשיות וחד פעמיות שהגיע יומן.
- **משימות מחזוריות** - משימה שסומנה כבוצעה עוברת ללשונית "הושלמו" וחוזרת לרשימה במועד הבא שלה:
  - *יומית* - חוזרת מחר.
  - *שבועית* - **אפשר לבחור כמה ימים בשבוע**; בכל יום שנבחר היא מופיעה ברשימת "היום".
  - *חודשית* - **אפשר לבחור כמה תאריכים בחודש**; תאריך שלא קיים בחודש קצר (29-31) מוצג ביום האחרון של החודש.
  - *כללית* - חד פעמית עם תאריך יעד; מופיעה ב"היום" ביום היעד, ומסומנת "באיחור" אם עבר.
- **תזכורות** - שעת התראה לכל משימה, כולל נודניק (10 דקות / שעה) ללא שינוי השעה הקבועה של המשימה.
- **מדיה** - הקלטה קולית (בדפדפן או ברשמקול המכשיר), צילום/העלאת תמונה, והכתבה קולית לשם המשימה.
- **גיבוי** - ייצוא ושחזור של כל הנתונים כקובץ JSON.
- **עיצוב** - מותאם מובייל, ניווט תחתון, מצב כהה, ותמיכה מלאה ב-RTL.

## איך התזכורות עובדות ברקע

האפליקציה משתמשת בכמה שכבות כדי להזכיר גם כשהמסך כבוי:

1. **Service Worker + התראות מערכת** - התזכורת מוצגת כהתראה של המכשיר, גם כשהאפליקציה ברקע.
2. **Notification Triggers** - בדפדפנים שתומכים, התזכורות מתוזמנות מראש (עד 14 יום) ומצלצלות גם כשהאפליקציה סגורה.
3. **Periodic Background Sync** - באנדרואיד/כרום, בדיקה תקופתית של תזכורות שהגיע זמנן.
4. **השלמה בפתיחה** - תזכורת שהוחמצה מוצגת ברגע שחוזרים לאפליקציה.

**לתוצאה הטובה ביותר:** להתקין את האפליקציה למסך הבית, לאשר הרשאת התראות,
ובאנדרואיד לבטל "חיסכון בסוללה" לאפליקציה.

> מגבלה אמיתית: אפליקציית דפדפן אינה יכולה להבטיח צלצול מדויק לשנייה כשהמכשיר בשינה עמוקה.
> תזכורת שהוחמצה תמיד תוצג בפתיחה הבאה. לצלצול מובטח נדרשת אפליקציה מקומית (native).

## מבנה הפרויקט

| קובץ | תפקיד |
|------|-------|
| `index.html` | האפליקציה כולה - ממשק ולוגיקה |
| `sw.js` | Service Worker: עבודה ללא רשת + תזכורות ברקע |
| `manifest.webmanifest` | הגדרות PWA (התקנה למסך הבית) |
| `tailwind.css` | Tailwind שנבנה מקומית (ללא תלות ב-CDN) |
| `icon-*.png` | אייקונים להתקנה |

## הרצה מקומית

הקבצים סטטיים לחלוטין. יש להגיש אותם משרת (ולא לפתוח כקובץ), כדי ש-Service Worker
וההתראות יעבדו:

```bash
npx http-server -p 8080
```

הנתונים נשמרים ב-IndexedDB על המכשיר בלבד ואינם נשלחים לשום שרת.
